# Beauty Video Gallery 🎬💄

縦型ショート動画（720 × 1280, 9:16）を美しく快適に閲覧できるWebギャラリーです。

## 特徴

- ✨ **洗練されたラグジュアリーデザイン**: ビューティー・コレクションに最適なローズゴールド＆ダークプレミアムテーマ
- 📱 **2つの閲覧モード**:
  - **グリッドモード**: サムネイル一覧とマウスホバーによる自動プレビュー再生
  - **ショート / リールモード**: スクロールや上下キーで次々と動画を楽しめるTikTok・Reels風ビュー
- 🎥 **多機能カスタムプレイヤー**:
  - 再生 / 一時停止
  - シークバー / バッファ進捗表示
  - 音量・ミュート切り替え
  - 再生速度変更（0.75x 〜 2.0x）
  - ループ再生切替
  - フルスクリーン表示
  - 動画ファイルの直接保存（ダウンロード）
- ⌨️ **キーボードショートカット**:
  - `Space`: 再生 / 一時停止
  - `←` / `→`: 5秒スキップ（戻る / 進む）
  - `↑` / `↓`: 前 / 次の動画へ切り替え
  - `M`: ミュート切り替え
  - `F`: 全画面表示
  - `Esc`: プレイヤーを閉じる
- ⚡ **高速読み込み**: QuickLookで事前生成した高精細サムネイルにより、初期表示が極めて軽量

## ローカルでの閲覧方法

ブラウザで直接 `index.html` を開くだけです：
```bash
open index.html
```
またはローカルサーバー（Python等）:
```bash
python3 -m http.server 8000
# http://localhost:8000 をブラウザで開く
```

## GitHub Pages での公開方法

1. GitHub リポジトリ（`csdkotsuka/beauty`）の **Settings** > **Pages** に移動します。
2. **Build and deployment** の Source で **Deploy from a branch** を選択します。
3. Branch で `main` / `/(root)` を選択し、**Save** をクリックします。
4. 数分で `https://csdkotsuka.github.io/beauty/` として公開されます。
